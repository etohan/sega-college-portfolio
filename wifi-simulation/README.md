# ネットワークシミュレータns-3用のWi-Fiシミュレーション

## 概要

C++とネットワークシミュレータns-3を用いて制作した、Wi-Fi通信性能評価シミュレーションです。

1台のアクセスポイントに複数の端末を接続し、各端末からアクセスポイントへUDPデータを送信するアップリンク環境を構築しています。

端末数やコンテンションウィンドウ（CW）などの条件を変更し、通信性能の違いを比較できます。

## 開発環境

- C++
- ns-3

## 主な機能

- AP・STAの生成
- Wi-Fi通信環境の構築
- 各端末の位置設定
- STAからAPへのUDP通信生成
- CWmin / CWmaxの設定
- 送信レート・パケットサイズの設定
- スループットの算出
- パケット損失率の算出
- 平均遅延の算出
- コマンドラインによる条件変更
- 入力値の確認
- CSV形式での結果保存

## 変更可能な主な条件

- 端末数
- CWmin / CWmax
- 送信レート
- パケットサイズ
- シミュレーション時間
- 通信開始時間

## 評価指標

### スループット

一定時間に正常に受信できたデータ量を算出します。

### パケット損失率

送信したパケットのうち、正常に受信できなかった割合を算出します。

### 平均遅延

パケットを送信してから受信されるまでの平均時間を算出します。

## ソースコード

`src/wifi-cw.cc`

シミュレーション条件の設定からWi-Fi環境の構築、通信生成、性能評価、結果出力までをC++で実装しています。
