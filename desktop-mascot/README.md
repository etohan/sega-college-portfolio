# デスクトップマスコット

## 概要

Unityを用いて制作したデスクトップマスコットアプリです。
デスクトップ上に3Dキャラクターを表示し、ユーザーの操作や時間経過に応じてキャラクターが動作します。

## 開発環境

- Unity
- C#

## 主な機能

- 3Dキャラクターの表示
- マウスによるキャラクターのドラッグ移動
- 一定時間ごとのランダムなモーション再生
- キャラクターの向き制御

## ソースコード

`src/` フォルダに、アプリで使用している主要なC#スクリプトを掲載しています。

### DragModelWithMouse.cs

マウス操作によってキャラクターを移動する処理です。
Raycastを用いてキャラクターへのクリックを判定し、ドラッグ中はマウスのスクリーン座標をワールド座標へ変換してキャラクターの位置に反映します。

### RandomAnimatorController.cs

キャラクターのモーションを制御する処理です。
一定時間ごとに複数のモーションからランダムに選択して再生します。
また、直前に再生したモーションを記録し、同じモーションが連続して選択されないようにしています。

### FaceCamera.cs

キャラクターがカメラ方向を向くように姿勢を制御する処理です。

### JumpPosition.cs

起動後にキャラクターを指定した位置へ移動する処理です。
